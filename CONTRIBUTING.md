# Updating FutureMakers labs

This is a public learner resource. Keep each lab clear, safe, and easy to read.

## Small edit in the GitHub website

1. Open the lab's `README.md`. Click the pencil icon to edit.
2. Make the change and use **Preview** to check links, headings, and lists.
3. Choose **Create a new branch** and **Propose changes**. Add a short note about what you changed.
4. Ask another BBR Academy staff member to review the pull request before it is merged. The reviewer should check technical accuracy, plain language, working links, platform terms, and accessibility.
5. If the learner content changed, update `assignment.pdf` in the same lab folder before merging. If you cannot make the PDF yet, flag that in the pull request and wait to publish both versions together.

## Adding a lab

1. Add a new folder under `labs/`, such as `02-telemetry/`.
2. Put the learner instructions in that folder's `README.md` and a matching `assignment.pdf` beside it.
3. Add the new lab to the table in the root `README.md`.
4. Test both links from the root page and from the community post before publishing.

## What belongs here

Include learner instructions, approved training links, a glossary, submission steps, and public templates. Keep private learner work, personal information, internal rubrics or review notes, live credentials, and answer keys out of this repository.

**Before publishing a new lab:** Put game passwords and classroom join links in a matching free community access location in the free apprenticeship preparation course. Keep the public Markdown and PDF free of those details. Check both versions before uploading. For Lab 01, upload an "assignment material" called **Lab 01 access** with the classroom link and passwords. Keep this public page useful even to someone who have not joined other activities yet.

Use short sentences. Keep necessary technical terms and explain them the first time or in the glossary. Check that learners can complete the lab without a required one-on-one meeting.
